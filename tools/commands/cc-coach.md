현재 세션의 **건강 상태를 진단**하고, 지금 시점에 맞는 Claude Code 활용 팁을 제안해줘.

## 진단 항목

### 1. 컨텍스트 상태 체크

아래 기준으로 현재 상태를 판단:

- **대화 길이**: 지금까지 주고받은 턴 수 체감 (많으면 `/compact` 제안)
- **주제 일관성**: 한 주제에 집중하고 있는지, 여러 주제가 섞였는지
- **수정 반복**: 같은 파일을 여러 번 고치고 있는지 (3번 이상이면 접근 방식 재고 제안)
- **에러 루프**: 같은 에러가 반복되는지 (다른 접근법 제안)

### 2. 현재 모드 적절성

- Plan Mode가 필요한 상황인데 Normal인지
- Auto-accept인데 신중해야 할 작업인지
- Thinking 모드가 도움될 복잡한 문제인지

### 3. 모델 적절성

현재 작업 난이도 대비 모델 선택:
- 단순 작업에 Opus 쓰고 있으면 → Sonnet 전환 제안 (비용 절감)
- 복잡한 아키텍처 작업에 Sonnet이면 → Opus 전환 제안
- 서브에이전트 활용 가능한 작업이면 → 위임 제안

### 4. 작업 효율 팁

현재 하고 있는 작업 패턴에 맞는 구체적 팁:
- 파일 여러 개 탐색 중 → "서브에이전트로 탐색 위임하면 컨텍스트 절약됩니다"
- 테스트 반복 중 → "실패한 것만 보려면 서브에이전트에 위임하세요"
- 리팩토링 중 → "Plan Mode에서 전체 계획 잡고 가면 더 빠릅니다"
- 디버깅 중 → "`Alt+T`로 Thinking 켜면 추론 깊이가 올라갑니다"

## 출력 형식

```markdown
## CC Coach

### 세션 상태
| 항목 | 상태 | 제안 |
|------|------|------|
| 컨텍스트 | (상/중/하) | (있으면 제안) |
| 모드 | (현재 모드) | (전환 필요시 제안) |
| 모델 | (현재 모델) | (전환 필요시 제안) |

### 지금 할 수 있는 것
- (현재 상황에 맞는 구체적 팁 1~3개)

### 한줄 요약
> (현재 상태를 한 문장으로)
```

## 규칙
- 3줄 이내로 핵심만. 장황한 설명 금지
- 문제 없으면 "깔끔합니다" 한마디면 충분
- 매번 같은 말 반복하지 말고, 현재 상황에 맞는 것만
- 비판 아닌 제안 톤으로
